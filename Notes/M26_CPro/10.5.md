# Recursion
Recursion is a powerful tool to help in code. Recursion calls a piece of code within that piece of code. i.e., a function which calls itself. Most problems can be solved with both an iterative method and a recursive method, but often one is easier or more efficient to implement.

**Syntax**
1. Base Case: To prevent a recursion of infinite depth, we need to have somewhere to end the recursion. This is called the base case.
2. Recursive Call: This is the part where you call the function itself.
3. Function Logic: This is the regular code for the function in addition to the above.

The base case must occur **before** the recursive call (the condition to check for the base case must occur before the recursive call). The remaining function logic can be written anywhere in the function.

**Examples**
Factorial
```C
int fact(int n){
	if(n==0 || n==1)
		return 1; // base case
	return n * fact(n-1); // recursive call
}
```


The same can also be implemented iteratively:
```C
int fact(int n){
	int answer = 1;
	for(int i = 2; i <= n; i++){
		answer *= i;
	}
	return answer;
}
```

Sum of `n` Natural Numbers
```C
int son(int n){
	if (n)
		return n + son(n-1);
	return 0;
}
```


Sum of digits
```C
int sod(int x){
	if(x)
		return x % 10 + sod(x/10); // recursion
	return 0; // base case
}
```

(Again, it can be implemented iteratively)


#### Positive Integer Exponent (Direct)
```C
int pow(int x, int p){ // to return x^p
	if (p == 0)
		return 1;
	return x * pow(x, p-1);
}
```

Time Complexity: $O(p)$
This is because, for each $p$, we will call $p-1$. 
This means we will end up calling $p, p-1, p-2, \ldots, 1, 0$.

Instead of calling the pow function `n` times, we can optimise it by splitting the function call based on the principle:
$$x ^ {2n} = ({x^n)}^2$$

This greatly reduces the time complexity of the function, in an optimisation method similar to binary search. (Divide and Conquer)


#### Positive Integer Exponent (Optimised)

```C
int pow(int x, int p){
	if (p == 0)
		return 1; // base case
	int a = p / 2;
	int b = p - a;
	int c = pow(x, a); // recursive call
	if (a == b)
		return c * c;
		// instead of this, if you write pow(x, a) * pow(x, a), there would be no change in time complexity because you are still calling it as many times.
		// to reduce the time complexity, it is necessary to call it only once
	return c * c * x;
}
```

Time Complexity: $O(\log p)$
This is because for each $p$, we only call $p/2$.
This means we will end up calling $p, \frac p 2, \frac p 4, \frac p 8, \ldots, \frac p p$

NOTE: Both of these methods can also be implemented iteratively. The time complexity depends on the **method**, not just on the fact that a recursive function is being used.



#### Fibonacci
```C
int fib(int n){
	if (n == 0)
		return 1;
	if (n == 1)
		return 1;
	return fib(n-1) + fib(n-2);
}
```

We can optimise by reducing one function call, which will make it equivalent in time complexity to the iterative method.

```C
int * fib(int n){
	if (n == 1){
		int * x = (int*) malloc(2 * sizeof(int)); // To avoid malloc, one can declare the array in main and then use it as an argument for the function.
		x[0] = 1;
		x[1] = 1;
		return x;
    }
	int * x = fib(n-1);
	int temp = x[1];
	x[1] += x[0];
	x[0] = temp;
	return x;
}

// answer is in x[1]
```


# Memoisation
Memoisation is an optimisation tactic in which we store the computed function outputs every first time the function is called for a given value. For every subsequent function call for that same value, we don't compute it again. Instead, we can just check if the value is there in the array. Then we simply use that value.

NOTE: Memoisation is not necessary for Recursion. Recursion is not necessary for Memoisation.


Example: Let us write code for fibonacci using memoisation.


```C
#include<stdio.h>
#define MAX 1000 // it is important that this is properly defined, assuming the cosntraints.
int memo[MAX] = {0}; // GLOBAL

int fib(int n){
	if (memo[n]) // accessing the memo
		return memo[n];
	int answer = fib(n-1) + fib(n-2);
	memo[n] = answer; // storing the memo
	return answer;
}

int main(){
	memo[0] = 1;
	memo[1] = 1;
	// compulsory intialisation of memoisation array as shown above.
	printf("%d", fib(5)); //example
	return 0;
}

```
