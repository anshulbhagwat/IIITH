# Sorting
Sorting is any way to arrange elements in a specified order. Often, for numbers, we may want to sort them in ascending or descending order. Let us consider the simple case of sorting an array of integers in ascending order. Without loss of generality, this case can be expanded to sorting other datatypes or sorting in descending order by changing the method for comparison. 
There are many ways to do this. Let us discuss some of them as given below.

We will be discussing three main methods.
1. Selection Sort
2. Bubble Sort
3. Insertion Sort

All of them have the same complexities.
Space Complexity: $O(n)$ needed for the array itself
Time Complexity: $O(n^2)$ (each needs two nested loops)
## Selection Sort
Selection sort works by finding the least element (minimum) iteratively. So, in the first iteration, we find the smallest number and put it in the first position. We know that all the remaining numbers are greater than or equal to this number. So we can put this number in the beginning, swapping it with the number which was in that position. Now, we find the next smallest number in the remaining array. Again, this means that this number is lesser than or equal to all the remaining numbers. So we can put it in the second position. Similarly, we keep finding the smallest out of the remaining numbers in each iteration, and add it to the end of the part of the array which we know is sorted.

```C
for (int i = 0; i < n - 1; i++){
	int min_id = i; // Maintain the minimum for that iteration
	for(int j = i+1; j < n; j++){
		if(arr[min_id] > arr[j])
			min_id = j; // updating minimum
	}
	int temp =  arr[min_id];
	arr[min_id] = arr[i]; // swap
	arr[i] = temp; // setting the i^th minimum number in the i^th iteration in the i^th array index	
}
```


```
Original Array: 99 3 8 2 0 6 2 -45 
Array after 0^th iteration: -45 3 8 2 0 6 2 99 
Array after 1^th iteration: -45 0 8 2 3 6 2 99 
Array after 2^th iteration: -45 0 2 8 3 6 2 99 
Array after 3^th iteration: -45 0 2 2 3 6 8 99 
Array after 4^th iteration: -45 0 2 2 3 6 8 99 
Array after 5^th iteration: -45 0 2 2 3 6 8 99 
Array after 6^th iteration: -45 0 2 2 3 6 8 99 
Sorted Array: -45 0 2 2 3 6 8 99 
```

### Complexity Analysis:
Space Complexity: $O(n)$ needed for the array itself
Time Complexity: $O(n^2)$ needed because we have to iterate through every array index (outer for loop) and find the minimum in the remaining (inner for loop).

## Bubble Sort
In bubble sort, we keep pushing the maximum number to the right. So, in the $i^{th}$ iteration, the maximum $i$ numbers are determined and are on the right side of the array. We do not change them for the rest of the loops. We keep swapping two neighbouring numbers based on which is larger.

```C
for (int i = 0; i < n - 1; i++){
		for (int j = 0; j < n - 1 - i; j++){// we iterate through the remaining numbers, which are guaranteed to be lesser than or equal to the n-i^th number at this point
		if (arr[j] > arr[j+1]){// if they are in the wrong order
			int temp = arr[j];
			arr[j] = arr[j+1];
			arr[j+1] = temp;
			// Swapping the two numbers
		}
	}
}
```


```
Original Array: 99 3 8 2 0 6 2 -45 
Array after 0^th iteration: 3 8 2 0 6 2 -45 99 
Array after 1^th iteration: 3 2 0 6 2 -45 8 99 
Array after 2^th iteration: 2 0 3 2 -45 6 8 99 
Array after 3^th iteration: 0 2 2 -45 3 6 8 99 
Array after 4^th iteration: 0 2 -45 2 3 6 8 99 
Array after 5^th iteration: 0 -45 2 2 3 6 8 99 
Array after 6^th iteration: -45 0 2 2 3 6 8 99 
Array after 7^th iteration: -45 0 2 2 3 6 8 99 
Sorted Array: -45 0 2 2 3 6 8 99
```
## Insertion Sort
This method tracks the first $i$ elements and ensures that they are properly sorted. So in the $i+1^{th}$ iteration, it needs to find the correct place to put the $i+1^{th}$ element because it is guaranteed that the other numbers before it were correctly sorted in the $i^{th}$ iteration.

```C
for (int i = 1; i < n; i++){
	int prev = arr[i];
	for (int j = 0; j < i; j++){
		if (prev < arr[j]){
			int temp = arr[j];
			arr[j] = prev;
			prev = temp;
		}
	}
	arr[i] = prev;
}
```


```
Original Array: 99 3 8 2 0 6 2 -45 
Array after 1^th iteration: 3 99 8 2 0 6 2 -45 
Array after 2^th iteration: 3 8 99 2 0 6 2 -45 
Array after 3^th iteration: 2 3 8 99 0 6 2 -45 
Array after 4^th iteration: 0 2 3 8 99 6 2 -45 
Array after 5^th iteration: 0 2 3 6 8 99 2 -45 
Array after 6^th iteration: 0 2 2 3 6 8 99 -45 
Array after 7^th iteration: -45 0 2 2 3 6 8 99 
Sorted Array: -45 0 2 2 3 6 8 99 
```


Note: For all of these sorting methods, you can iterate from $i$  $0$ till $n-1$ instead of $0$ till $n$ because it is guaranteed to be sorted after $n-1$ iterations. (from $1$ till $n$ for insertion sort). i.e., an array of one element is always sorted.


# Example Code for Sorting

**Example of Selection Sort**

```C
int arr[] = {99, 3, 8, 2, 0, 6, 2, -45};
int n = 8;

printf("Original Array: ");
for(int i = 0; i < n; i++){
	printf("%d ", arr[i]);
}
printf("\n");


for (int i = 0; i < n - 1; i++){
	int min_id = i;
	for(int j = i+1; j < n; j++){
		if(arr[min_id] > arr[j])
			min_id = j;
	}
	int temp =  arr[min_id];
	arr[min_id] = arr[i];
	arr[i] = temp;
	
	
	printf("Array after %d^th iteration: ", i); // for your understanding
	for(int k = 0; k < n; k++){
		printf("%d ", arr[k]);
	}
	printf("\n");
	
}


printf("Sorted Array: ");
for(int i = 0; i < n; i++){
	printf("%d ", arr[i]);
}
printf("\n");
```
