# Operators

### Arithmetic
`+` addition
`-` subtraction
`*` multiplication
`/` division
`%` modulus

For arithmetic operations, if both arguments are of type `int`, then the output will also be `int` necessarily. `int` takes the floor value of a `float` by default.

Example: `5/18` is `0`. But `5.0/18` gives you the float value.

### Logical
Logical operators take two boolean arguments and output a boolean output. i.e., the output can only be 0 or 1.
If the inputs are not already boolean, their boolean values will be considered (boolean typecasting).

Consider two boolean variables `A` and `B`
We have the following boolean operators.

| `A` | `B` | `A && B` | `A \|\| B` | `!A` |
| --- | --- | -------- | ---------- | ---- |
| `0` | `0` | `0`      | `0`        | `1`  |
| `0` | `1` | `0`      | `1`        | `1`  |
| `1` | `0` | `0`      | `1`        | `0`  |
| `1` | `1` | `1`      | `1`        | `0`  |

### Bitwise
Bitwise operators act on the stored binary values of a variable. They are not the same as logical operators which can take only `0` and `1` as inputs.
Bitwise and for example, takes the and of each bit of two integers.

Ex.
`25 & 21 = 11001 & 10101 = 10001 = 17`
`25 && 21 = 1 && 1 = 1`

| Operator | Operation   |
| -------- | ----------- |
| `&`      | Bitwise AND |
| `\|`     | Bitwise OR  |
| `^`      | Bitwise XOR |
| `<<`     | Left Shift  |
| `>>`     | Right Shift |
| `~`      | Bitwise NOT |

Left shift and right shift move the binary values of the number to the left or right.
Ex.
`5 << 2 = 101 << 2 = 10100 = 20`
`35 >> 3 = 100011 >> 3 = 100 = 4`

### Conditional
Conditional operators take in two arithmetic (integer, float, etc.) values and return a boolean value

| Operator | Operation                |
| -------- | ------------------------ |
| `==`     | equal to                 |
| `!=`     | not equal to             |
| `>`      | greater than             |
| `>=`     | greater than or equal to |
| `<`      | lesser than              |
| `<=`     | lesser than or equal to  |




# Conditions
`if` and `else` statements are used to check conditions in C.
Sometimes, we need to conditionally perform different actions.
i.e. we need to branch away from linear code. without conditionals, we would have to perform one linear code without any changes. this is not possible sometimes.

For example, if I want to write code which takes the absolute values of a variable, I need to negate it if it is negative, but do nothing if it is positive. Here, we use `if`

`if` takes a boolean value, and performs the action if the boolean value is 1. if you provide a non-boolean value, it will be typecasted to the boolean value.

```C
if (a < 0){
	a = -a;
}

// OR if it is just one line, you can also write:
if (a < 0)
	a = -a;
```


Now if there are multiple conditions, then we can use `else` as well.
`else` executes only if the first `if` failed.

Ex. consider that there is an integer `a` to which I need to add 4 if `a` is negative, 5 if it is between 0 and 5, and subtract 10 otherwise
```C
if (a < 0)
	a += 4;
else if (a <= 5)
	a += 5;
else
	a -= 10;
```

Another way to write conditions in C is to us `switch` - `case` syntax. Say there is an integer x and y, and you have to write a programme such that if x is 0, then you need to add 5 to y, if x is 1, you need to subtract 5 from y, if x is 2 then you need to multiply 5 into y, and otherwise you need take the modulus of y with 5.
There are two ways to do this, which are equivalent.

You can write `if` `else` statements 

```C
if (x == 0)
	y += 5;
else if (x == 1)
	y -= 5;
else if (x == 2)
	y *= 5;
else
	y /= 5;
```

Or you can write `switch` `case` statements

```C
switch(x){
	case(0):
		y += 5;
		break;
	case(1):
		y -= 5;
		break;
	case(2):
		y *= 5;
		break;
	default:
		y /= 5;
		break;
}
```

If you don't use break, it will keep going through the rest of the switch code, which can sometimes cause issues, depending on the usage.


`if` takes boolean inputs, and typecasts it otherwise
`switch` can take any input, and it compares the variable with the values in `case`



# Loops
Loops are pieces of code that you can run multiple times. i.e. if you want to run the exact same code 10 times or 100 times, maybe with different values, or with some other reason. This is where you use loops.

In C, there are two main types of loops: `for` and `while` loops.

`for` loops have three (optional) arguments:
1. initialisation step: this is what the code will do before the loop begins
2. termination condition: this is when the code will stop, if you don't specify this, the code will keep running forever
3. update step: this is what the code will do *after* every time it runs the code

```C
for(init; term; update){
	// code_to_repeat ...
}
```

a `while` loop does the same thing as a `for` loop, but there is no initiation or update inbuilt (i.e. you have to separately initialise or update it yourself)

```C
while(term){
	// code_to_repeat ...
}
```


Ex. Let us say you want to print "A\n" one hundred times.
You could do this by writing `printf("A\n");` one hundred times. But this is very time consuming for you. Maybe 100 times you can do it manually. But what if you need to do it 100000 times?

Loops solve this.

```C
int n = 100; // how many times?

for (int i = 0; i < n; i++){
	printf("A\n");
}

// or equivalently, the while loop does the same thing, but with init and update outside the brackets
int j = 0; // init
while (j < n){
	printf("A\n");
	j++; // update
}
```

Both of these codes do the same thing:
1. the initialisation is `int i = 0`. This runs once and initialises a variable `i` and sets its value to 0.
2. the termination condition is `i<n`. *Before* each loop, it checks whether `i` is indeed lesser than `n`. If it is not lesser, it will stop running the code and comes outside the loop.
3. the update step is `i++`. *After* each loop, it increases the value of `i` by 1.


There is another loop in C, called `do` - `while` loop. The only difference between `while` and `do`-`while` is that in `do`-`while`, the code will run at least once before checking the condition.
(i.e., the checking for the termination condition is after each loop, not before)



```C
int k = 0;
do{
	printf("A\n");
	j++;
}while(j < n);
```

This does the same thing as the code above in this example.


### `continue` and `break`

`continue` just continues the loop (i.e. skip the remaining code for that loop and start the loop again)
`break` just breaks the loop (i.e. gets outside the loop)
