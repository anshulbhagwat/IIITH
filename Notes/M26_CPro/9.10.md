`fgets` is another way to get input in C
**Syntax**
```C
char str[100];
fgets(str, 100, stdin);
printf("%s", str);
```

This takes an input for a whole line, until `"\n"`, taking in at most count-1 characters, and setting the last character to `"\0"` (NULL terminator). This is the main benefit (preventing buffer overflow error, since it limits the total number of characters it takes in as input).

`fputs` similarly is for output

You can look into the documentation for further understanding: [fgets](https://en.cppreference.com/c/io/fgets)
# Random Numbers
the function to get random numbers in C is `rand` in the library `<stdlib.h>`

```C
#include<stdio.h>
#include<stdlib.h>
# include<time.h>


int main(){
	//
	srand(time(NULL)); // this sets a random seed based on the current time index
	// if you don't do this, rand() will always return the same sequence of numbers

	int a = rand(); // gives you and integer between 0 and RAND_MAX
	// if I want a range, I can use it as below
	
	int min = -320;
	int max = 33;
	
	int b = rand() % (max - min + 1) + min;
	// this gives you a random number between max and min (inclusive)
	
	// if I want a float, I can use it as below
	 float c = ((float) rand()/ (float) RAND_MAX) * (max - min) + min;
	 // min and max can be floats or ints
	return 0;
}
```


# Function
Functions are one way to modularize code. Basically, you can take one logic, with certain inputs, and certain outputs, and write the code for it separately. You can always call it any time in the other parts of the code.
It is like a mini programme withing your programme.

For example, let us say I want to find the absolute value of a number many times in my code. Instead of writing the code to find the absolute value multiple times, I can write a function to find the absolute value, and then use it any number of times without writing the code for it again.

### Syntax
```C
#include<stdio.h>

// declaring and defining a function
int abs(int a){
	if (a < 0)
		return -a;
	return a;
}

int main(){
	int x = -33;
	int y = abs(x); // calling a function
	
	printf("%d %d\n", x, y);
	
	// -33 and 33
	
	
	int c = 66;
	int d = abs(54-c);
	
	printf("%d %d", c, d);
	
	// 66 and 12
	
	return 0;	
}
```

`(int a)` or whatever is inside the brackets represents the inputs
if I wanted to take no inputs, I can leave the brackets empty `()`
`int abs` -> `int` is the output (return type) of the function which we are naming `abs` 


**Print Triangle**
```C
#include<stdio.h>
void print_triangle(int n); // another way to declare but not define a function
// declaration of a function must be before the main function
// definition can come after main, if and only if the declaration is done before main


int main(){
	int N;
	scanf("%d", &N);
	print_triangle(N);
	return 0;
}


// defining the function later
// this is compulsory without which the programme would not compile
void print_triangle(int n){
	printf("\n");
	for (int i = 0; i < n; i++){
		for (int j = 0; j <= i; j++){
			printf("*");
		}
		printf("\n");
	}
	return; // optional for void return type
}


```

let us say I want to write a function to print a triangle of size `n`
then I would need one input integer (`n`) and no outputs
so, the definition would need to be of `void` type, and the *arguments* would be just one of type `int`
