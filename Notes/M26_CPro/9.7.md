
# Arrays
Arrays are a structure to store multiple variable of the same data type. Address space for arrays is contiguous (i.e., when you declare an array, addresses are allocated in one single block for the whole array.)

The size of arrays is somewhat fixed. I cannot declare an array of size 4 and then try to access a 5th number.

### Syntax
**Declaring an Array**
```C
int a[size]; // declaring an integer array of size 'size' and name 'a'
// this is basically declaring 'size' integer variables in consecutive addresses
```

You can also declare a fixed-size array and define its values.

```C
int a[3] = {5, 77, 2352};
// or equivalently
int a[] = {5, 77, 2352};
// because you can drop the size if you are going to define the entire array
```


**Array Input and Output**
Let's say we need to take in $n$ numbers, and print each number.
```C
int n;
scanf("%d", &n);

int arr[n]; // declaring an array of size n
for(int i = 0; i<n; i++){
	scanf("%d", &arr[i]); // input into the i^th variable of i
}
for(int i = 0; i<n; i++){
	printf("%d ", arr[i]); // printing the i^th variable of i
}
```

**Size of Arrays**

```C
int arr[13];

int arr[13];
printf("%d %d %d",sizeof(&arr), sizeof(arr), sizeof(arr[0]));

// output is 8, 52, 4
```

`sizeof(arr[0])` is the size of one integer because `arr[0]` is an integer
`sizeof(arr)` gives the total size in bytes of the array
`sizeof(&arr)` for any array of any type is always going to give you `8` because that is the size of a *pointer*.
# Strings
Strings are essentially arrays of characters. Unlike other data types, you can take string inputs and outputs in one line.

```C
char name[100];
scanf("%s", name); // or &name. for strings, both will work
// let's say we gave input : "Hello World!"
printf("%s", name); // here it has to be name
// output will be "Hello" because it reads till the space (or any special character)
```

You have to make sure that the size of the entered string doesn't exceed the allocated space (like 100 in the above example).

Some special characters which break string inputs (`scanf`): "\n", " ", "\t"
Special character which breaks string outputs (`printf`): "\0" (the above characters don't break strings while printing, only '\0' does)

i.e.
```C
printf("%s", "Are \n you ready \t?\0 Let's find out");
```
output is
```
Are 
 you ready 	?
```


There are also some special functions for strings in C. They are there in the library "string.h"

Documentation: [Standard library header <string.h>](https://en.cppreference.com/c/header/string)
It is important to learn to read documentation. It is the authentic first hand source and it is always supposed to be correct.

Some useful functions:
1. `strcpy`: copies one string into another.
2. `strcat`: joins two strings together.
3. `strlen`: gives you the integer length of the string
4. `strcmp`: compares two strings alphabetically
There are also functions which let you specify the length (ex. `strncpy` vs `strcpy`)

Example:
```C
char a[100] = "sea";
char b[100] = "horsewell";
char c[100];
strncpy(c, b, 5); // dest, source, n
strcat(a, c);
printf("%s", a);
// output is "seahorse"
```

(remember to `#include <string.h>`)

**Print a string in reverse**
```C
char name[] = "!nuf si gnimmargorP";
for(int i = strlen(name) - 1; i >= 0; i--){
	printf("%c", name[i]);
}
// output is "Programming is fun!"
```

**Print a string in reverse wordwise**
```C
char sentence[] = "gnimmargorP si yllaer !nuf";
int n = strlen(sentence);
int l = 0;
int r = 0;
while (l < n){
	while(r < n && sentence[r] != ' '){
		r++;
	}
	for(int j = r - 1; j>=l; j--){
		printf("%c", sentence[j]);
	}
	printf(" ");
	l = r+1;
    r = r+1;
}
// output is "Programming is really fun!"
```

### XOR Property
The following are some _mathematical_ properties of XOR which can be used in code as well.
1. Self-Inverse: $$X\wedge X =0$$
2. Identity: $$X\wedge 0 = X$$
3. Associativity: $$X\wedge Y = Y\wedge X$$
This can be used for example, to find the one unique number in an array with paired numbers. One can simply XOR all the numbers together.

Reminder: there is no inbuilt power operator in C.  `^` is the XOR operator, not a power operator.
there is a function `pow(base, exponent)` in `<math.h>`

# Complexity and Complexity Analysis

This is a way of describing how much resource (time or space (memory)) a programme needs to run. You can look up 'Big O Notation'.
$O(n)$ space complexity means you need $c\cdot n$ variables for a programme of size $n$.
$O(n)$ time complexity means you need $c\cdot n$ operations for a programme of size $n$.

(Order of $n$ -> $c\cdot n$, $c$ is a fixed constant)

Similarly, $O(n^2)$ means you need $c\cdot n^2$ operations
Ex. Comparing every element of an array of size $n$ with every other element.

Similarly $O(\log n)$ means you need $c\cdot n^2$ operations
Ex. binary search on a pre-sorted search space of size $n$ (like an array of size $n$)

While these concepts may not be very useful in the course "Computer Programming", it will be much more useful and maybe unavoidable in "Data Structures and Algorithms" as well as "Algorithm Analysis and Design".
