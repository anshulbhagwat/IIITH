
### Russian Peasant Algorithm
(Multiplication of Non-Negative Integers)
When we want to find the product of two numbers without using the multiplication algorithm, we can use this algorithm using bitwise operators.
In each iteration, we divide one number by 2 (left shift by one), and multiply the other side by 2 (right shift by one). Each time the number we are dividing is odd, we add the other number to the answer.

```C
int answer = 0;
int a = 18;
int b = 23;

while (a){
	if (a & 1){
		answer += b;
	}
	a = a >> 1;
	b = b << 1;
}

printf("%d", answer);
```

The reason this works, is because in each iteration, we are considering the $i^{th}$ least significant bit of `a`, and we are adding $2^i$ times `b` if that $i^{th}$ bit is one. This is multiplication.

Logic:
1. In the $i^{th}$ iteration, we have `(a >> i) & 1`. This is the $i^{th}$ least significant bit of `a`.
2. In the $i^{th}$ iteration, we have `b << i`. This is $2^i$ times `b`.
3. By conditionally adding this to the answer, we are performing traditional binary multiplication.

Note: this method is for non-negative integers. It will not work for negative integers.

# Square Root
How can we find the square root of a number without using the inbuilt method `sqrt()` of library `math.h`?

#### **Naïve Method/ Exhaustive Method** 
First, we there is the naïve method where we check every number from `0` till `n`. 

The following method is for an integer which has a perfect square root.

(*Integers*)
```C
int x = 16;
int answer = 0;
for(int i = 0; i <=x; i++){
	if (i*i == x){
		answer = i;
		break;
	}
}
```

We can do the same thing for floats, by defining a precision and checking in increments of that precision. Here however, the answer will not necessarily be exact. It will be as close as defined by the precision. 
(This method again only works for non-negative floats)

(*Floats*)
```C
float precision = 0.01;
float x = 390;
float answer = 0;

while (answer * answer <= x){
	answer += precision;
}

printf("%f", answer);
```


#### **Binary Search**
In binary search, we start with some search space, and using our knowledge of the answer, we keep reducing the search space by half, until we find the answer.

This works, because we know that the answer is going to be between some left boundary (0) and some right boundary (the number itself). This is our entire search space. We can reduce our search space because for any number we can know if the answer is smaller or larger than that number. This method is called binary search. This method can be used for any other such problem where we know the boundaries and we have a way to reduce the search space by determining some information.

```C
float precision = 0.01;
float x = 390;
float answer = 0;
float l = 0; // this is the left boundary of the search space
float r = x; // this is the right boundary of the search space


while (fabs(answer * answer  - x) > precision){
	answer = l + r;
	answer = answer / 2;
	
	
	if (answer * answer  > x){
		r = answer; //  this reduces the search space to the left, we now only need to check values lesser than answer
	}
	else{
		l = answer; // similarly, this reduces the search space to the right, we are now only going to check values greater than the answer
	}
}

printf("%f", answer);
```

Note: Include the relevant library to use `fabs` (`#include<math.h>`)
